WebMCP bridge · MIT licensed

Any website, any agent.

A website can now declare typed tools for AI agents — but today only one browser's assistant can call them. anybridge opens the page, captures those tools, and hands them to Claude, GPT, LangChain, or anything else that speaks MCP. Sites that declare nothing still work: it brings its own.

$ anybridge serve https://your-site.com Nothing to install. The browser downloads itself on first run.

How it works

Two layers, so no site is left out.

anybridge runs a real browser, injects a shim before any page script executes, and mirrors whatever it finds as a standard MCP server. Every call runs inside the live page, so the site's own code does the work.

Layer one · when the site cooperates

Its own tools, forwarded

The shim defines navigator.modelContext and document.modelContext, capturing every registerTool call the page makes — including the native ones it would otherwise reserve for Chrome's built-in assistant. Typed arguments, structured results, no guessing.

Layer two · when it doesn't

Seven tools that always work

Roughly every site on the web declares nothing at all. For those, anybridge supplies its own: read the page as clean markdown, follow links, list and submit real forms, type into single-page apps, click what a human would click.

A real call, on a real store

The difference structured tools make.

bauzaar.it is an Italian pet store running on Shopify, which registers WebMCP tools on its storefronts. Asked the same question, the site's own tool returns clean records where scraping returns prose.

search_catalog({ catalog: { query: "crocchette gatto sterilizzato" } })

Purina Pro Plan LiveClear Adult — sterilised cat, salmon €19.89
Purina Pro Plan LiveClear Adult — sterilised cat, turkey €18.19
Collection: dry food for sterilised cats 1 match

Verbatim output, product IDs and next-step hints omitted for width. The same session can then call update_cart — the store's tool, not a simulated click.

Use it

One line for a client. One import for a framework.

As an MCP server it plugs into any MCP client. As a library it hands your framework the tool objects it already understands — one browser session behind all of them, so calls share page state.

Add the site as a server. Its tools appear in the next session.

# one command, nothing installed beforehand
claude mcp add mysite -- anybridge serve https://your-site.com

In claude_desktop_config.json — the same shape works for Cursor, Cline, and any other MCP client.

{
  "mcpServers": {
    "mysite": {
      "command": "anybridge",
      "args": ["serve", "https://your-site.com"]
    }
  }
}

Real StructuredTool objects, ready for an agent graph.

from anybridge import BridgeSession
from langgraph.prebuilt import create_react_agent

async with BridgeSession("https://www.bauzaar.it/") as site:
    agent = create_react_agent("anthropic:claude-sonnet-5", site.langchain_tools())
    result = await agent.ainvoke(
        {"messages": [("user", "Find food for a sterilised cat, compare prices")]}
    )

Function-calling schemas, and one dispatcher for whatever the model asks for.

async with BridgeSession("https://your-site.com") as site:
    tools = site.openai_tools()          # schemas for the request
    text  = await site.call(name, args)   # run what the model chose

CrewAI, LlamaIndex, Pydantic AI, or a loop you wrote yourself — plain dicts, no adapter needed.

site.tool_specs()   # [{"name", "description", "input_schema"}, ...]
site.anthropic_tools()               # Claude API tool definitions
await site.call("read_page", {})       # returns text
site.page                            # the raw browser, for anything else

The built-ins

What every site gets, declared or not.

ToolWhat it does
read_pageThe page as clean markdown — headings, links, tables, code. Scope it with a CSS selector.
navigateOpen a URL and return what loaded.
list_linksEvery link with its text and target, filterable.
list_formsForms with their fields, labels, options and required flags.
submit_formFill a form and submit it; returns the resulting page.
type_textType into an input found by placeholder, label or selector — works in React apps with no form at all.
clickClick a link or button by the words a human would read. Handles cookie banners and new tabs.

Tested on

Thirty-plus live sites, not fixtures.

Every fix in this project came from a real page breaking: a platform's CSS hiding content from the extractor, a bot challenge redirecting mid-read, a form field shadowing a DOM property.

The plain web
info.cern.ch — the first website ever published — and a bed & breakfast in Parma.

Where it stops. A site behind a dedicated CAPTCHA wall — Google Search, for one — will refuse any automated browser, anybridge included. The agent receives the refusal page and can say so, rather than inventing an answer.

What it won't decide for you. It fills carts and forms because a person asked it to. The last step of a purchase stays where it belongs: with the human, or with a tool the site deliberately published for it.

Install

Get it.

$ pip install git+https://github.com/JustVugg/anybridge.git $ pip install "anybridge[langchain] @ git+https://github.com/JustVugg/anybridge.git"

Python 3.10 or newer. Chromium downloads itself the first time you run it; on a bare Linux box, sudo playwright install-deps chromium supplies the system libraries it needs.
